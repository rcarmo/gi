## Quick Action prefill

Gi now replaces the editor draft with the exact slash command selected in Quick Actions. `/model`, `/compact` and `/skill:proof` no longer acquire a trailing space, and skill selection no longer prepends itself to an older draft. The existing attachment stays attached. Selection focuses the editor and places its caret at the command's end; no message is sent until an explicit submission. A user can then type skill arguments before sending.

The installed Piclaw 3.2.4 bundle is the reference. `make test-piclaw-quick-action-prefill` passed Chromium and WebKit at phone, tablet and desktop sizes (6/6), checking exact `/model` and `/skill:proof` values, focus, caret, one retained attachment pill and zero prompt requests. The probe validates the installed source-map provenance. Its APIs are isolated; it does not mutate a live model or execute a real skill.

The native Quick Actions suite passed in complete split groups: Chromium 69/69 and WebKit 69/69. The skills fixture passed 12/12, including explicit arguments, session-switch fencing, retained media, failed stale/unknown commands and Settings focus. `make check ux-parity-inventory` passed 144 functional tests (11 skipped), 211 support tests (7,951 assertions), Go tests/vet and build checks. Supplied component files were not modified; the build-time adapter now only guards delayed prefill focus after unmount or Settings takeover.

A combined 138-case Quick Actions run hit its outer command limit at case 128. One intermediate Chromium-tablet run failed because its test assumed an extra `<p>` wrapper around a visible history message; the corrected locator passed in isolation. Another Chromium-phone run briefly failed to find the composer on startup; the test passed unchanged in isolation and in the full 69-case rerun. An initial standard check failed the obsolete functional expectation of `/model `; it passed after updating that expectation. None of the browser or assertion timeouts was increased.

These tests support the bounded slash-prefill clauses only. No Classic/Shared mapping was added. Broader palette behaviour, real-provider skill execution, physical keyboards, untested browser errors, the immediate-reload draft race and whole-web UX contracts remain in `features/VALIDATION.md`.
