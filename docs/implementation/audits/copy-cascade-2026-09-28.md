# Message copy and reply deletion against Piclaw 3.2.4

Installed Piclaw copied source Markdown and code text in six browser/viewport cases. Its reply-aware deletion controls were observed separately in Chromium and WebKit desktop. Gi copies Markdown but cannot yet perform the combined `@ux-original-024` cascade journey.

`make test-piclaw-copy-controls` runs `tests/ux/oracle/piclaw-copy-ui-probe.mjs` on shipped Piclaw 3.2.4 assets with a disposable timeline. Chromium and WebKit phone, tablet and desktop cases each copied `# Source Markdown` as plain Markdown, included `<strong>Bold</strong>` in the rich clipboard data, copied `const value = "<世界>";\n` from the code block, and retained `keep unsent draft`. The probe captures trusted browser `copy` events, not the operating system clipboard. Results: `test-results/ux-oracle/copy-controls/evidence.json` and `/workspace/tmp/gi-copy-oracle-final.log`.

`ORACLE_BROWSER=chromium|webkit bun tests/ux/oracle/piclaw-deletion-ui-probe.mjs` passed with disposable timeline and DELETE routes (`/workspace/tmp/gi-delete-oracle-{chromium,webkit}-current.log`). Cancelling the visible three-reply confirmation sent no DELETE and retained four rows; accepting sent `cascade=true` and removed them. The hidden-reply 409 fixture retried with `cascade=true` on confirmation or left the parent after dismissal. The fixture creates the 409 response; an earlier installed backend-function probe returned 200 for an unseen reply and orphaned it, as recorded in [the deletion review](ux-reaudit-2026-09-26/message-deletion-review.md).

Gi's focused source-Markdown copy test passed 6/6 (`/workspace/tmp/gi-copy-native-focused.log`). `make check ux-parity-inventory` passed 144 functional tests with 11 skips and 214 support tests with 7,977 assertions (`/workspace/tmp/gi-copy-check.log`). Gi still calls `deletePost(id,false,originChat)` and rejects `cascade=true` in `internal/web/message_delete.go`; it has no persisted reply graph. `@ux-original-024` stays unmapped. These fixture runs did not exercise production Piclaw HTTP routing, authentication, live deletion, or OS clipboard behavior.
