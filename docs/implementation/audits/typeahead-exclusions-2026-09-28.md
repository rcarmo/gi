# Quick Actions typeahead exclusions, Piclaw 3.2.4

Installed Piclaw 3.2.4 opened Quick Actions from the timeline and kept it closed for composer, session search, workspace tree and editable CodeMirror typing in six browser/viewport cases. Ten further excluded targets passed as synthetic DOM keyboard fixtures. Gi has a read-only workspace preview, so the Classic CodeMirror journey has no native equivalent in this slice.

`make test-piclaw-typeahead-exclusions` runs `tests/ux/oracle/piclaw-typeahead-exclusions-probe.mjs` against the shipped Piclaw browser assets with isolated APIs. Chromium and WebKit phone, tablet and desktop cases each opened the palette with `q` on the timeline, closed it with Escape, and retained the composer draft after typing `z`. The shipped session picker accepted search input without opening Quick Actions. Its workspace tree and a file opened in the shipped CodeMirror editor retained keyboard ownership; the editor received `q` while the palette remained closed. Synthetic input, textarea, select, contenteditable, composer, editor, workspace, dialog, popup and dock targets did not open the palette. Evidence: `test-results/ux-oracle/typeahead-exclusions/evidence.json`; final Makefile log: `/workspace/tmp/gi-typeahead-live-final.log`.

An earlier test sampled the open palette before its passive focus/effect cycle and sent Escape too soon; the popup remained visible. The corrected probe waits for the palette search field to own focus and a further animation frame. Failed attempts remain in `/workspace/tmp/gi-typeahead-oracle-live-attempt{3,4}.log` and `/workspace/tmp/gi-typeahead-oracle-final.log`.

Gi's existing native-input exclusion test passed 6/6 (`/workspace/tmp/gi-typeahead-native.log`). A new read-only-tab journey in `tests/ux/quick-actions.spec.mjs` checks trusted typing on the real workspace tree and active tab, then returns to the conversation to verify its draft and session. The complete Quick Actions spec passed 72/72 Chromium and 72/72 WebKit in split runs (`/workspace/tmp/gi-typeahead-native-{chromium,webkit-final}.log`). Initial attempts assumed that the mobile workspace stayed open after opening a tab and that the composer remained mounted beneath a visible preview; corrected assertions follow the actual mobile view transition. `make check ux-parity-inventory` passed 144 functional tests with 11 skips and 214 support tests with 7,977 assertions after the added browser test (`/workspace/tmp/gi-typeahead-native-preview-check.log`). The Classic `@ux-original-004` outline stays unmapped: Gi's read-only preview lacks Piclaw's editable CodeMirror pane. Installed Piclaw uses mocked file/tree APIs, with no physical keyboard or production deployment test.
